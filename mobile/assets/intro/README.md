# Intro video slot

영상을 **직접 제작**해서 여기 넣으면 됩니다.

**`universe-birth.mp4`**

넣은 뒤 `npm run sync:intro`(또는 `npm start` / `npm run typecheck`) 한 번 실행하면 Metro가 그 파일을 번들합니다. 파일이 없으면 **합성 태양 연출**이 같은 핸드오프 포즈로 재생됩니다.

## Spec (앱 핸드오프와 맞춤)

- Aspect: **9:16** portrait
- Length: ~**4.0s** (마지막 **0.5s** 거의 정지)
- End frame: **따뜻한 금빛 구체 하나**, 화면 중앙, 텍스트·로고·사람 없음
- Sphere diameter ≈ **프레임 너비의 42%**
- Color ≈ `#F0C36A` · glow `#FFE6A8`
- 카메라 최종 위치·크기 고정

상세: `docs/your-diary/19-universe-intro-3d.md`
