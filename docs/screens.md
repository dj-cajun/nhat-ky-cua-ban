## 화면별 상세

### S-01 랜딩 (`/`)

**구성 요소**
- 히어로: 서비스명 + 한 줄 소개
- 주요 기능 3가지 (간편 기록, 태그, 프라이버시)
- CTA: "시작하기" → `/signup`, "로그인" → `/login`

**상태**
- 로그인된 사용자 접근 시 → `/diary`로 리다이렉트

---

### S-04 일기 목록 (`/diary`)

**구성 요소**
- 헤더: 앱 타이틀, 설정 링크, "+ 새 일기" 버튼
- 검색창
- 태그 칩 필터 (가로 스크롤)
- 일기 카드 리스트: 제목, 날짜, 기분, 본문 미리보기(2줄), 태그

**빈 상태**
- 일러스트 + "아직 일기가 없어요" + "첫 일기 쓰기" 버튼

---

### S-05 일기 작성 (`/diary/new`)

**폼 필드**
| 필드 | 타입 | 필수 | 기본값 |
|------|------|------|--------|
| 제목 | text | O | — |
| 본문 | textarea (markdown) | O | — |
| 날짜 | date picker | O | 오늘 |
| 기분 | emoji picker | X | — |
| 태그 | multi-select / creatable | X | — |

**액션**
- 저장 (primary)
- 취소 → 목록

---

### S-06 일기 상세 (`/diary/[id]`)

**구성 요소**
- 제목, 날짜, 기분, 태그
- 본문 (markdown 렌더)
- 수정 / 삭제 버튼
- 뒤로가기 → 목록
