## S-02 메인 홈 — 5층 레이아웃

```
┌────────────────────────────────────────┐
│ [1층] StatusBar: TODAY 24 | TOTAL 1204 | 🌰 도토리 5 │
├────────────────────────────────────────┤
│ [2층] ProfileCard: 명함 프로필 (Warp 시 실루엣)      │
├────────────────────────────────────────┤
│ [3층] VisitorTicker: 최근 방문자 → 워프 포탈         │
├────────────────────────────────────────┤
│ [4층] CalendarWidget | PhotoAlbumWidget (2칸)        │
├────────────────────────────────────────┤
│ [5층] SwipeCardStack: 2D 제스처 카드 덱               │
└────────────────────────────────────────┘
```

### 뷰 모드

| 모드 | 프로필 | 글쓰기 | 방명록 |
|------|--------|--------|--------|
| My Home | 실명 + 사진 | 비밀 카드 O | — |
| Stranger Home | Họ: [성씨] + 실루엣 | X | O |

### S-01 온보딩 힌트

- 입력: 성별, 키 범위, MBTI 앞자리, 등교 수단
- 저장: Web Crypto SHA-256 단방향 봉인 — **원본 미저장**
- UI 카피 예: *"Trưa nay ăn bún bò ngon lắm"*, *"nhìn nhau cười kk"* (100% tiếng Việt Gen Z)

### 디자인 토큰

| 토큰 | 값 |
|------|-----|
| 배경 | `bg-[#faf9f6]` |
| 먹선 | `border-[1.5px] border-slate-800` |
| 뷰포트 | `h-screen overflow-hidden` |

## S-05 피드 카드 규칙

- 리스트: 🤫 익명 / Ẩn danh 고정, 성씨 미노출
- 본문: 최대 3줄 truncate
- 미디어: 📸 🎥 🔗 아이콘만, 썸네일 금지
- 터치: 상세 모달 → 미디어·댓글 활성화
- 작성자 터치: 워프 → Stranger Home

---

## S-04 투표 Lock

- 트리거: 매일 17:00 푸시 + 5층 → 투표 카드 자동 전환
- Lock: 12문항 미완료 시 스와이프·워프 차단
- 선택지: 반 친구 실명 4지선다
- 제출 전: 힌트 실드 1종 선택 (성씨/키/성별/등교수단)
