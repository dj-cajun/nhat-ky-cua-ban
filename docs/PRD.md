# PRD — 제품 요구 사항 정의서

> **프로젝트**: Nhật ký của bạn (나의 일기)
> **버전**: 0.1.0-draft
> **최종 수정**: 2026-07-02

---

## 1. 제품 개요

### 1.1 목적
사용자가 매일의 생각과 경험을 쉽고 안전하게 기록하고, 나중에 다시 읽을 수 있는 개인 일기 서비스.

### 1.2 타겟 사용자
- 일상을 기록하고 싶은 개인 사용자
- 모바일·웹 어디서든 빠르게 메모하고 싶은 사용자

### 1.3 핵심 가치
- **간편함**: 최소한의 클릭으로 일기 작성
- **프라이버시**: 개인 데이터 보호
- **회고**: 날짜·태그 기반 검색으로 과거 기록 탐색

---

## 2. 기능 요구 사항

### 2.1 Must Have (MVP)
| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| F-01 | 회원가입/로그인 | 이메일 또는 소셜 로그인 | P0 |
| F-02 | 일기 작성 | 제목, 본문, 날짜, 기분(이모지) | P0 |
| F-03 | 일기 목록 | 날짜순 정렬, 미리보기 | P0 |
| F-04 | 일기 상세/수정/삭제 | CRUD 전체 | P0 |
| F-05 | 태그 | 일기에 태그 추가 및 필터 | P1 |

### 2.2 Should Have
| ID | 기능 | 설명 | 우선순위 |
|----|------|------|----------|
| F-06 | 검색 | 제목·본문·태그 검색 | P1 |
| F-07 | 다크 모드 | 시스템/수동 테마 전환 | P2 |
| F-08 | 이미지 첨부 | 일기에 사진 1~3장 | P2 |

### 2.3 Won't Have (이번 버전 제외)
- 소셜 공유 / 피드
- 협업 일기
- AI 일기 요약

## 3. 비기능 요구 사항

| 항목 | 기준 |
|------|------|
| 응답 속도 | 페이지 로드 < 2초 (3G 기준) |
| 가용성 | 99.5% uptime |
| 보안 | HTTPS, 비밀번호 해싱, 세션 만료 |
| 접근성 | WCAG 2.1 AA 목표 |

## 4. 성공 지표 (KPI)

- DAU / MAU
- 일기 1편 이상 작성한 사용자 비율 (7일 내)
- 7일 리텐션

- 초기 배포: Vercel + Supabase (또는 TRD 확정 후 변경)
