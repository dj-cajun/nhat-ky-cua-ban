## 1. 제품 개요

### 1.1 목적
베트남 고등학생을 위한 Zalo 미니앱 기반 **100% 익명 소셜 다이어리** 서비스. 성씨(Họ)와 일기로 연결되는 반 수사극 경험을 제공한다.

### 1.2 타깃 사용자
- 베트남 고등학생 (Gen Z / Gen Alpha)
- 호치민·하노이 대도시 중심
- Zalo 일상 사용자

### 1.3 핵심 슬로건
> "100% 완전 익명으로 쓰고, 성씨(Họ)와 일기로 훔쳐보는 우리 반 수사극"

### 1.4 핵심 가치
- **완전 익명**: 피드·댓글은 🤫 익명 / Ẩn danh 고정
- **수사극**: 투표·힌트 실드·워프로 범인 찾기
- **집단 도파민**: 반 단위 실시간 동기화
- **토큰 이코노미**: 광고·제휴·미션 → 도토리(Dotori) 충전

## 7. 성장 저해 요인 교정 (v1.1)

### 7.1 힌트 데이터 보안 (F-01 보완)

**문제**: 클라이언트 XOR + 로컬 UUID 키는 가역적이며, JS 소스 노출 시 힌트 전체 유출 가능.

**교정**:
- 온보딩 제출 시 Web Crypto API `SHA-256`으로 필드별 해시 생성
- DB(`profiles.hint_data`)에는 **해시(digest) + 공개 쉴드 문구(shields)** 만 저장
- 원본 `HintData`는 메모리에서 즉시 폐기 (복호화 API 제거)
- 레거시 XOR 데이터는 앱 부팅 시 자동 마이그레이션
- 프로덕션: 해시 pepper는 `VITE_HINT_PEPPER` 환경 변수 + 서버 측 HMAC 권장

### 7.2 베트남어 현지화 (Phase 4)

**문제**: 데모 시드·UI에 한국어 혼재 시 현지 Gen Z 거부감 유발.

**교정**:
- 모든 사용자 노출 문자열 → `src/i18n/vi.ts` 단일 사전
- 시드 데이터(`presets/hochiminh.ts`, `mock-data.ts`) → 남부 고등학생 구어체 100%
- 한국어는 개발자 문서(`docs/`)와 profanity 필터 블랙리스트에만 유지

## 8. 도토리 이코노미 (v1.2)

> **원칙**: PG 결제 없음. 도토리는 광고·미션으로 **모으고**, 수사·방어·소통·꾸미기·**선물**에 **쓴다**.  
> **공통 API**: `spendDotori(userId, amount, reason)` + 일별·대상별 중복 구매 제한.

### 8.1 획득 (Earn)

| 경로 | 보상 | 반복 |
|------|------|------|
| 가입 기본 | 5 🌰 | 1회 |
| 보상형 광고 | +2 🌰 | 무제한 |
| Shopee 미션 | +2 🌰 | 1회/일 |
| TikTok 미션 | +3 🌰 | 1회/일 |
| **선물 수신** | +N 🌰 | 타인이 보낸 만큼 |

### 8.2 🔍 수사용 힌트 (공격)

| ID | 아이템 | 가격 | 설명 | 1일 제한 |
|----|--------|------|------|----------|
| D-01 | 성씨 첫 글자 | 2 🌰 | `Họ: ●●●●` → `N…` (Nguyễn 등) | 대상당 1회 |
| D-02 | 추가 힌트 1개 | 3 🌰 | 미공개 실드(MBTI·등교수단 등) 1종 강제 해제 | 대상당 2회 |
| D-03 | 지목자 소거 | 5 🌰 | 나를 투표한 4명 후보 중 1명 소거 | 1회/일 |

**진입점**: 21시 지목 알림, Stranger Home, 투표 아카이브.

### 8.3 🛡️ 익명 방어 실드 (방어)

### 8.6 🎁 선물하기 (Gift)

반 친구에게 **익명·실명 선택**으로 도토리 또는 꾸미기 아이템을 보내는 소셜 소비처.  
워프(Stranger Home)·방명록·투표 아카이브·TODAY 방문자 목록에서 **「Tặng quà」** 진입.

#### 8.6.1 선물 종류

| ID | 선물 | 가격 (보내는 사람) | 수령 |
|----|------|-------------------|------|
| G-01 | 도토리 봉투 | 3 / 5 / 10 🌰 | 수신자 잔액 +동일 (수수료 없음) |
| G-02 | 테마 선물 | 5 🌰 | 수신자 `themeId` 적용 (미보유 시) |
| G-03 | 프로필 데코 선물 | 3 🌰 | 수신자 `badgeEmoji` 적용 |
| G-04 | 스티커 팩 선물 | 2 🌰 | 수신자 달력 스티커 +3 |
| G-05 | 미스터리 박스 | 4 🌰 | 데코·스티커·1🌰 중 랜덤 1종 |

#### 8.6.2 UX 규칙

- **익명 선물 (기본)**: 발신자 🤫, 수신자에게 「Ai đó tặng bạn…」+ 선물 내용만 표시
- **실명 선물 (옵션)**: +1 🌰 추가 — 「Nguyễn M.A. tặng bạn 🌰×5」
- **메시지 카드**: 선물과 함께 10자 이내 메시지 (Profanity Shield)
- **수신함**: My Home 1층 StatusBar 옆 🎁 배지 — 미확인 선물 N건
- **답선**: 수신 후 「Cảm ơn 🤫」1🌰 또는 방명록 무료 작성 1회 unlock

#### 8.6.3 제한·안전

| 규칙 | 값 |
|------|-----|
| 같은 반(`class_id`)만 선물 가능 | 필수 |
| 본인에게 선물 | 불가 |
| 1일 발송 상한 | 5건/인 |
| 동일 수신자 1일 상한 | 2건 |
| 도토리 봉투 1일 상한 | 20 🌰 (송신 합계) |
| 차단 목록 | 선물·쪽지 동시 차단 |
