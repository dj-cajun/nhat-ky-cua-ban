# 26 — 100점짜리 정식 앱 기획

> **상태**: 기획 고정 (구현 대기)  
> **최종 갱신**: 2026-07-27  
> **목표**: App Store에 올릴 수 있는 **정식 제품 (v1.0)** — “데모처럼 보인다”가 아니라 **실계정·실데이터·실기기로 하루를 쓰고 방문하는 앱**  
> **디자인 잠금**: 다이어리 = **현재 파스텔 연필 미니홈피** (`DiaryHompyHome`)  
>   · 셸 교체 · 어두운 장면 전면화 · 카드형 홈피 재설계 = **v1.0까지 금지**

> 이전 오해(「100명」)는 폐기. 본 문서는 **완성도 100점 = 정식 출시 기준**이다.

---

## 1. 제품 한 줄

> 같은 학교라는 문 안에서, 세 사람이 연 작은 서클로 들어가,  
> **파스텔 미니홈피**에 오늘을 남기고 조용히 방문한다.

```text
학교 = 입장 경계
서클 = 관계 단위
다이어리(현재 홈피 UI) = 제품 중심 · 시각 정체성
```

코어 플로우 (바꾸지 않음):

```text
실로그인
→ 학교 인증
→ 인트로(1회)
→ 우주
→ 서클 방
→ 원 탭
→ 파스텔 미니홈피
→ 오늘 쓰기 · 방문 · 게시판 · (쪽지/공지/음악)
```

|---|------|-----------|

## 3. 잠금 / 정식 밖

### v1.0까지 잠금

| 항목 | 고정 |
|------|------|
| 다이어리 UI | `DiaryHompyHome` 파스텔 OutlineBox · 점지 · 프로필 · 주간 · 앨범 · 게시판 · 음악 슬롯 |
| 네비 | 인트로 → 우주 → 서클 방 → 원 → 홈피 |
| 관계 | 학교 ≠ 서클 · 조용한 방문(조회수/방문알림 없음) |

### v1.0에 넣지 않음 (정식 이후 백로그)

- 학교 전체 피드 / 전교 검색 / 학교 익명판  
- 채팅 앱화 · 스토리 · 공개 탐색 · 알고리즘  
- 꾸미기 상점 · 방문자 카운터 · 도토리/보상 · 랭킹  
- 앱 내 Spotify 풀 플레이어 (카드·딥링크만 v1.0)  
- 홈피 셸 재디자인 · 장면 스트립 전면화  
- 포커스룸 고도화 · 멀티스쿨 마켓 확장 · 웹 풀패리티

## 5. S1 — 정식 뼈대

목표: 데모 버튼을 빼도 코어 루프가 돈다.

| 항목 | 내용 |
|------|------|
| 홈피 실데이터 | 오늘 일기 · 주간 · 방명록 · 자유 · 써클보드 미리보기 |
| 우주/서클 | 실서클·실멤버 오브 · 원 탭 → `/diary/[userId]` |
| close-3 | 수동 로컬 유지 OK · 자동 친밀도 금지 |
| 로그인 | Apple 실동작 · 세션 · (Google/email은 준비 상태 명확히) |
| 학교 | 코드 요청→상태 UX→verified 가드 |
| staging | JWT·RLS·교차학교 deny 실측 |
| 기기 | iOS에서 인트로→홈피→쓰기 1회 |

완료 조건: **데모 계정 없이도** 위 루프 녹화 가능.

---

## 6. S2 — 제품 완성도 (홈피 UI는 그대로)

목표: 정식 앱처럼 “서클 안에서 살 수 있다”.

| 영역 | v1.0 범위 |
|------|-----------|
| 공지·투표 | 서클당 활성 1 · 응답 후 주홍 |
| Presence | 초록 접속 · 실패해도 서클 열람 유지 |
| 가명 게시판 | 작성·목록 · 실명 ID 비노출 |
| 쪽지 | 홈피에서 의도적 진입 · 최소 compose/읽기 |
| 음악 | Spotify 카드 · 외부 열기 |
| 앨범/캘린더 | 홈피 슬롯 + 기존 라우트 유지 (과한 리디자인 금지) |
| 안전 | 신고·차단 · ops 큐 · 스냅샷 |
| 품질 | empty/error/offline · EN/KO · 딥링크 재검사 |
| 설정 | 계정 · 차단 목록 · 인트로 다시보기 · 삭제 |

완료 조건: 보안 하드 게이트([15](./15-beta-launch-checklist.md) A) + 서클 생활 체크리스트 통과.

---

## 7. S3 — 클로즈드 베타

목표: 실사용자가 정식 후보 빌드를 쓴다. **기능 추가 금지**.

- 학교 1~2곳 코드 초대  
- ops: 인증 승인 · 신고 처리 · 정지  
- 허용 패치: 크래시 · 권한 · 일기 저장 실패 · 세션 누수  
- 금지: 홈피 리디자인 · 채팅 · 피드 · 새 메이저 모듈  

관측 질문:

1. 서클을 열었는가  
2. 친구 홈피에 들어갔는가  
3. 오늘을 썼는가  
4. 홈피 디자인이 바뀌어 헷갈렸는가 → 나오면 **되돌림**

## 8. S4 — 정식 v1.0 (100점 GO)

스토어 제출 직전:

- [ ] §2 100점 표 10항 전부  
- [ ] 프라이버시 정책 · 권한 사용 목적 (카메라/사진/추적 해당 시)  
- [ ] 데모 단축이 프로덕션 빌드 기본 경로가 아님  
- [ ] 크래시·보안·데이터 손실 블로커 0  
- [ ] 카피: Your Diary / 「너의 다이어리」 정체성 일치  

**GO** → TestFlight/App Store 제출  
**NO-GO** → S2/S3로 복귀 (범위 확장으로 해결하지 않음)

## 9. S5+ — 정식 이후 (별도 기획)

v1.0이 안정된 뒤에만 논의:

- 포커스룸 / 집중 오브제  
- 홈피 **가산** 연출 (베이스 셸은 유지한 채)  
- 멀티스쿨 · 초대 성장  
- 웹 패리티  

원칙: **베이스 홈피를 갈아엎지 않고** 얹는다.
