## 0. 「100점」의미 (내부 전용)

> **100점**은 완벽하다는 뜻이 아니다.  
> 현재 정의한 **v1.0 출시 필수 조건(GO 체크리스트)을 모두 통과**했다는 **내부 표현**이다.

- 품질 판정은 숫자보다 **GO / NO-GO**가 정확하다.  
- 스토어 소개·외부 홍보에서 “100점짜리 앱” 표현을 **쓰지 않는다**.  
- 문서 제목의 「100점」은 팀 내부 약어로만 유지한다.

## 1. 제품 한 줄

> 같은 학교라는 문 안에서, 세 사람이 연 작은 서클로 들어가,  
> **파스텔 미니홈피**에 오늘을 남기고 조용히 방문한다.

```text
우주 = 들어가는 방식
파스텔 홈피 = 사용자가 머무는 제품
학교 = 입장 경계 · 서클 = 관계 단위
```

코어 질문 (구현·리뷰마다):

> 실제 계정으로 들어와서, 실제 친구의 홈피를 방문하고,  
> 실제 일기를 남겼는데 아무것도 깨지지 않는가.

코어 플로우:

```text
실로그인 → 학교 인증 → 인트로(1회) → 우주
→ 서클 방 → 원 탭 → 파스텔 미니홈피
→ 오늘 쓰기 · 방문 · 게시판 · (쪽지/공지/음악)
```

## 2. v1.0 GO 체크리스트 (내부 「100점」표)

아래를 **전부** 충족하면 정식 출시 **GO**. 하나라도 미달이면 **NO-GO** (베타/데모만).

| # | 영역 | GO 조건 |
|---|------|---------|
| 1 | 정체성 | 첫 화면부터 “폐쇄형 서클 다이어리 + 파스텔 홈피”로 읽힘 |
| 2 | 계정 | Apple 실로그인 · 세션 복구 · 로그아웃 · 계정 삭제 경로 |
| 3 | 학교 | 코드 인증 → verified · 미인증 서클 개척 불가 · 교차학교 deny |
| 4 | 관계 | 3인 개척 · 추천 가입 · 서버 단일 소스 |
| 5 | 공간 | 인트로→우주→서클→원→홈피 **데모 없이** 완주 |
| 6 | 홈피 | 현 파스텔 UI로 오늘 일기 CRUD · (이어서) 주간·앨범·게시판 |
| 7 | 서클 생활 | 공지/투표 1 · Presence · 가명보드 · 쪽지 최소 |
| 8 | 안전 | 신고·차단·ops · 가명 ID 비노출 · 세션 전환 누수 0 |
| 9 | 품질 | loading/empty/error/offline · 치명 크래시 0 · EN/KO |
| 10 | 출시 | **S4 Phase H 전수** · 실기기 · 스토어 메타·프라이버시 |

### 완료 판정 (기능)

> 화면이 존재하는 것은 완료가 아니다.  
> **실제 계정 · 실제 권한 · 실제 서버 데이터**로  
> **생성 · 조회 · 수정 · 실패 · 재진입**이 확인되어야 완료다.

## 3. 잠금 / 정식 밖

### 다이어리 디자인 잠금 + 예외

**잠금**: `DiaryHompyHome` 시각 구조·정체성 (OutlineBox · 점지 · 프로필 · 주간 · 앨범 · 게시판 · 음악 슬롯).

> **예외(허용)**: 접근성, 오류 표시, 키보드 회피, 작은 화면 대응, 터치 영역 확보.  
> 다만 홈피의 **시각 구조와 정체성은 변경하지 않는다**.

### 네비·관계 잠금

| 항목 | 고정 |
|------|------|
| 네비 | 인트로 → 우주 → 서클 방 → 원 → 홈피 |
| 관계 | 학교 ≠ 서클 · 조용한 방문(조회수/방문알림 없음) |

### 우주 배치 규칙 (v1.0) — `recent spatial layout`

**폐기**: `close-3` 수동 로컬 지정 · 편집 모드 · 친밀도 점수 · 상대 공개.

**채택**: 나만 보는 **최근 방문 기반** 로컬 표현.

목표 계층 (데이터가 충분할 때):

```text
최근 방문 1–3명  → 가까운 오브
최근 방문 4–7명  → 중간 거리
최근 방문 8–12명 → 먼 거리
나머지           → 작은 점
```

짧은 표기: **recent 3-4-5** (가까운 3 · 중간 4 · 먼 5 · 나머지 점).

규칙:

- 수동 지정 없음  
- 친밀도 계산 없음  
- 상대에게 공개 없음  
- 방문 기록이 없으면 **기본 서클 멤버 순서**로 임시 배치  

**S1 축소 허용** (우주가 코어 루프를 늦추면):

```text
가까운 최근 방문 3명 + 나머지 작은 점
```

3·4·5 전체 배치는 **시각 개선(S5+ 또는 S2 후반)** 으로 미뤄도 된다.  
핵심은 **직접 편집을 넣지 않는 것**이다.

### v1.0에 넣지 않음

- 학교 피드 / 전교 검색 / 학교 익명판  
- 채팅 앱화 · 공개 탐색 · 알고리즘  
- 꾸미기 상점 · 방문자 카운터 · 보상 · 랭킹  
- 앱 내 Spotify 풀 플레이어  
- 홈피 셸 재디자인 · 장면 스트립 전면화  
- 포커스룸 고도화 · 자동 친밀도 · 우주 3D 고도화

## 5. S1 — 정식 뼈대 (가짜 데이터 제거)

목표: **데모 없이도** 코어 루프가 돈다.  
목적은 예쁘게 만드는 것이 아니라 **실제 계정·권한·저장**이다.

### S1에서 절대 같이 하지 않음

- 홈피 색상/구조 재설계  
- 우주 3D 고도화 · 새 애니메이션 시스템  
- 포커스룸 · 음악 플레이어 확장 · 게시판 기능 확대  
- 자동 친밀도 · close-3 수동 편집 · 관리자 통계 추가  

### S1 구현 순서 (엄수)

#### S1-1 인증과 학교

```text
Apple 로그인 → 세션 복구 → 학교 상태 → verified 가드 → 로그아웃
```

사용자가 누구인지 확실하지 않으면 이후 데이터 연결은 의미 없다.

#### S1-2 서클과 라우팅

```text
실제 서클 목록 → 실제 멤버 → 원 탭 → /diary/[userId] → 권한 실패 처리
```

우주 배치: **recent 방문(또는 S1 축소: 가까운 3 + 점)**. 수동 편집 UI 없음.

#### S1-3 홈피 실데이터 (핵심 먼저)

1. 오늘 일기 조회 · 작성 · 수정 · 삭제  
2. 친구 일기 조회 · 공개 범위 적용  
3. (이어서) 주간 · 앨범 슬롯 · 게시판 미리보기  

UI는 `DiaryHompyHome` 유지. fixture/데모 시드를 **제품 기본 경로에서 제거**.

#### S1-4 실기기 (최소 1대 iPhone)

```text
설치 → 로그인 → 학교 인증 → 서클 → 친구 홈피 → 내 홈피
→ 일기 작성 → 앱 종료 → 재실행 → 세션·저장 확인
```

### S1 staging = **핵심 경로 smoke test** (≠ Phase H)

실데이터 연결 직후 권한·세션만 확인한다.  
Phase H 전수 런북([21](./21-phase-b1-staging-signoff.md))과 **혼동하지 않는다**.

S1 smoke 범위:

- 실로그인 JWT 동작  
- verified 접근 · 미인증 차단  
- 교차학교 차단 · 서클 비회원 차단  
- 일기 저장·조회  
- 계정 전환 후 이전 데이터 누수 없음  

> **S1**: 핵심 경로 staging **smoke test**.  
> **S4**: Phase H **전수 실측 + 최종 sign-off**.

S1 완료: 데모 없이 위 루프 **녹화 가능** + smoke PASS.

## 6. S2 — 제품 완성도

홈피 UI 그대로. 서클 안에서 “살 수 있게” 채운다.

| 영역 | v1.0 범위 |
|------|-----------|
| 공지·투표 | 서클당 활성 1 · 주홍 |
| Presence | 초록 · 실패해도 열람 유지 |
| 가명 게시판 | 작성·목록 · 실명 ID 비노출 |
| 쪽지 | 홈피에서 의도적 진입 |
| 음악 | Spotify 카드 · 외부 열기 |
| 앨범/캘린더 | 기존 라우트 · 과한 리디자인 금지 |
| 안전 | 신고·차단 · ops |
| 품질 | empty/error/offline · EN/KO |
| 우주 시각 | 가능하면 recent 3-4-5 완성 (S1 축소분이면 여기서) |

완료: [15](./15-beta-launch-checklist.md) A열 하드 게이트 + 서클 생활 실계정 검증.

## 7. S3 — 클로즈드 베타

**기능 추가 금지.** 허용 패치만:

- 저장 실패 · 권한 오류 · 길 잃음 · 크래시 · 세션 누수  

금지: “덜 썼으니 기능 하나 더”, 홈피 리디자인, 채팅, 피드.

관측: 서클 열림 / 친구 홈피 / 오늘 씀 / 홈피 디자인 혼란 → 혼란 시 **되돌림**.

## 8. S4 — 정식 v1.0 게이트

### Phase H 전수 (출시 전)

S1 smoke와 별개. A–E/M 매트릭스 전체 ([21](./21-phase-b1-staging-signoff.md)):

- 모든 RPC · 모든 딥링크 · known UUID  
- 캐시·사진 URL · pending_change · 정지 사용자  
- 운영자 권한 · mixed-school incident · 로그·감사 증거  

### 스토어 GO

- [ ] §2 GO 표 10항  
- [ ] Phase H sign-off  
- [ ] 프라이버시·권한 문구  
- [ ] 프로덕션 기본 경로에 데모 단축 없음  
- [ ] 치명 블로커 0  

**GO** → 제출 · **NO-GO** → S2/S3 (범위 확장으로 해결하지 않음)
