# 베타 출시 체크리스트

> **대상**: 30~60명 · 약 10개 서클 · 4주 비공개 베타  
> **현재 단계**: **11.5 실기기 출시 게이트** ([16](./16-phase-11.5-device-launch-gate.md))  
> **원칙**: 코드를 더 넓히지 않는다. **출시를 막는 문제만** 잡고, 게이트 통과 후 초대한다.  
> **금지**: 데모 단축·관리자 DB 수정으로 플로우 “통과”, 새 모듈·꾸미기·채팅·보상·공개 기능·앱 내 Spotify 재생

자동화(참고): `npm run test:security` · `npm run mobile:test` · Playwright  
**베타 시작 판정은 아래 실기기·staging 항목이 전부 초록일 때만.**
