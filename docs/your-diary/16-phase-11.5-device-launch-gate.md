# 11.5 — 실기기 출시 게이트

> **상태**: 🔜 진행 (코드 확장 금지 · 실기기·staging만)  
> **원칙**: 기능을 더 만들지 않는다. **출시를 막는 결함만** 잡고, 전부 통과하면 코드상 베타 준비 종료.  
> **체크리스트**: [15-beta-launch-checklist.md](./15-beta-launch-checklist.md)  
> **마이그레이션**: `007~018` 무수정. 필요 시 `019+`만 신규.

---

## 이 단계에서 하지 않는 것

```text
새 모듈 · 꾸미기 · 채팅 · 새 알림 · 보상 · 공개 기능
Minecraft · Spotify 앱 내부 재생 · 데모 단축 버튼 의존
관리자 DB 직접 수정으로 플로우 “통과” 처리
```

실기기에서 발견된 **블로커만** 최소 패치한다.

## 1. 배포 환경 재현 (빈 staging)

```text
007~018 마이그레이션 적용
→ Edge Functions 배포
→ Spotify·푸시 secret 등록
→ private Storage 확인
→ Realtime public access OFF
→ 기능 플래그 연결
→ 운영자 계정 지정
```

## 베타 시작을 막는 결함 (하나라도 → 수정 후 재검사)

* 다른 사용자 데이터 순간 노출
* 비멤버가 서클 내부 API 조회
* 가명 실제 신원을 일반 클라이언트가 수신
* 차단 후 콘텐츠·signed URL 접근
* 쪽지·가명 글 중복 전송
* DB 저장 없이 주홍 배지 표시
* service role 또는 Spotify secret 번들 존재
* 푸시 딥링크가 권한 검사 우회
* 운영자 신고 처리 불가
* 계정 전환 후 이전 계정 캐시 잔존

---

## 통과 후

```text
코드상 베타 준비 종료
→ 30~60명 · ~10개 서클 · 4주 비공개 베타
→ 버그·치명 사용성만 패치
→ 새 기능 PR은 베타 피드백 이후
```

결함 발견 시: **최소 패치 → 해당 게이트만 재실행**. 전체 기능을 다시 넓히지 않는다.
